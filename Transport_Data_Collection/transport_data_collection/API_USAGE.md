## 1️⃣ OpenWeather API

### 📋 Asosiy Ma'lumot

- **URL:** https://api.openweathermap.org
- **Dokumentatsiya:** https://openweathermap.org/api
- **Versiya:** 2.5
- **Autentifikatsiya:** API Key (URL parameter)

### 🔑 API Key Olish

1. https://openweathermap.org saytiga kiring
2. "Sign Up" tugmasini bosing
3. Email va parol bilan ro'yxatdan o'ting
4. Dashboard → API Keys bo'limiga o'ting
5. Default key'ni ko'chirib oling

**Free Plan Limitlar:**
- 1,000 so'rov / kun
- 60 so'rov / daqiqa
- 1,000,000 so'rov / oy
